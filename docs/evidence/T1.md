SIGINT 為 Ctrl+C 對應訊號；未另外驗證 Windows 互動主控台的實體按鍵。未驗證高負載或卡住請求下的關機。程式在收到訊號後提供 4 秒 drain 上限。

## 實作與限制

Config 驗證 PORT、ROOM_CAPACITY（1～50）、HTTP(S) origin 與日誌過濾器。預設來源為 http://localhost:5173；Origin 拒絕在 T2 實作。T1 尚無 WebSocket。

使用文件指定依賴，沒有額外直接依賴。建置鎖定 Cargo.lock；執行映像只有應用二進位與 distroless 系統執行庫，使用非 root。

關機 API 參考：https://docs.rs/axum/0.8.9/axum/serve/struct.WithGracefulShutdown.html

初次 Docker 引擎啟動期間一次 build 失敗，待引擎就緒後重試成功。首次組合驗證指令被自動審查拒絕（blocked by policy，未提供細節），改用 docker stop 傳送訊號完成驗證。
